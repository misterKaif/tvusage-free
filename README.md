# TVUsage Free — Open-Source Parental Control & Screen Time for Android TV

**TVUsage Free** — это бесплатная и открытая альтернатива платным приложениям родительского контроля для Android TV / Google TV (оптимизировано под Sony Bravia 4K, Android 9 Pie).

В отличие от существующих решений:
- ❌ **Нет подписок** и встроенных покупок.
- ❌ **Не блокирует рабочий стол** и кнопку HOME при включении телевизора.
- 🔒 **Экран блокировки строго 1-в-1 по минималистичному ТВ-дизайну** с вводом пароля стрелками пульта (D-Pad).
- 👑 **Родительский режим**: ввод мастер-кода или 1 клик на ТВ/в веб-панели полностью снимает ограничения до сна/выключения телевизора.
- 📱 **Веб-панель со смартфона**: локальный веб-интерфейс (`http://<IP_телевизора>:8080`) с авторизацией по паролю пульта, управлением общим таймером, быстрым добавлением времени (+10, +20, +30, +60 мин), переключателями приложений и статистикой за День/Неделю/Месяц.
- 🤖 **Telegram Бот**: удаленный запрос дополнительного времени от ребенка с кнопками одобрения прямо в чате Telegram.

## 📸 Интерфейс и возможности

1. **Экран блокировки по исчерпанию лимита:**
   - 6 больших круглых индикаторов.
   - Заполняются зелёным цветом при нажатии стрелок пульта (`Up` / `Down` / `Left` / `Right`).
   - Пароль **никогда не отображается в открытом виде**.
2. **Панель на телевизоре:**
   - Защищена мастер-кодом пульта.
   - Кнопка **«👑 Снять ограничения до сна ТВ»** — быстрый просмотр для взрослых без повторного ввода паролей до выключения телевизора.
   - Кнопка **«🔄 Сбросить время сегодня»**.
3. **Мобильная веб-панель управления (по домашнему Wi-Fi):**
   - Защита входом со стрелочной клавиатуры.
   - Живой учет секунд и минут контролируемых программ.
   - Быстрые кнопки продления: `+10 мин`, `+20 мин`, `+30 мин`, `+1 час`.
   - Выбор приложений под общий таймер (SmartTube, Kinopoisk, HDRezka и др.).
   - Статистика использования за день, неделю и месяц.

## 🛠️ Сборка проекта

Проект собирается автономно в Docker, без необходимости локальной установки Android SDK:

```bash
# 1. Собрать Docker-образ сборщика (JDK 17 + Android SDK 34)
docker build -t tvusage-builder ./tvusage_free

# 2. Скомпилировать APK
docker run --rm \
  -v "$(pwd)/tvusage_free":/project \
  -v "$HOME/.gradle":/root/.gradle \
  -w /project tvusage-builder ./gradlew assembleDebug --no-daemon
```

Готовый APK появится в:
`tvusage_free/app/build/outputs/apk/debug/app-debug.apk`

## 🚀 Установка на Android TV через ADB

1. Включите **Отладку по ADB** в настройках разработчика на Android TV.
2. Подключитесь к телевизору по локальной сети:
   ```bash
   adb connect <IP_ТЕЛЕВИЗОРА>:5555
   ```
3. Установите APK и выдайте системные разрешения:
   ```bash
   # Установка
   adb -s <IP_ТЕЛЕВИЗОРА>:5555 install -r tvusage_free/app/build/outputs/apk/debug/app-debug.apk

   # Выдача прав доступа к статистике и поверх других окон
   adb -s <IP_ТЕЛЕВИЗОРА>:5555 shell appops set com.tvusage.free GET_USAGE_STATS allow
   adb -s <IP_ТЕЛЕВИЗОРА>:5555 shell appops set com.tvusage.free SYSTEM_ALERT_WINDOW allow
   adb -s <IP_ТЕЛЕВИЗОРА>:5555 shell dumpsys deviceidle whitelist +com.tvusage.free
   ```
4. Запустите приложение:
   ```bash
   adb -s <IP_ТЕЛЕВИЗОРА>:5555 shell monkey -p com.tvusage.free -c android.intent.category.LAUNCHER 1
   ```

## 🔒 Безопасность и пароли по умолчанию

- **Родительский пароль по умолчанию:** `ВВЕРХ, ВВЕРХ, ВНИЗ, ВНИЗ` (`UP,UP,DOWN,DOWN`).
- Мастер-пароль можно изменить в веб-админке на любую комбинацию стрелок через запятую (например: `LEFT,RIGHT,UP,DOWN`).
- Никакие токены или пароли не хранятся в репозитории в открытом виде.
