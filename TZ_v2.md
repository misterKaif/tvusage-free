# Техническое задание (v2): Smart Kids TV Lock & Parental Control

## 1. Введение и цели проекта
Разработка легковесного, полностью бесплатного приложения родительского контроля для Android TV / Google TV. Приложение решает проблему чрезмерного просмотра ТВ детьми, устраняет критические недостатки существующих решений (отсутствие платных подписок, корректная работа кнопки HOME и пульта, удаленное управление).

---

## 3. Функциональные требования

### 3.1. Управление паролем на ТВ (D-Pad Code)
1. **Формат пароля**: последовательность из 4–6 нажатий стрелок пульта (↑, ↓, ←, →). Не требует экранной клавиатуры и мыши.
2. **Мастер-пароль (Родительский)**: снимает все ограничения на текущую сессию (до перехода ТВ в сон).
3. **Визуальный отклик**: анимация заполнения точек при нажатии, эффект вибрации/тряски (shake) при неверном коде.

### 3.2. Учет экранного времени и контроль приложений
1. **Трекинг активности**: фоновый сервис считывает текущее активное приложение (Foreground App) через `UsageEvents` / `AccessibilityService`.
2. **Учет времени только при просмотре**: таймер тикает только тогда, когда включен экран ТВ и активно разрешенное детское приложение (например, `SmartTube`, `Кинопоиск`).
3. **Соблюдение навигации пульта**:
   * **Кнопка HOME**: работает штатно в разблокированном состоянии и внутри разрешенных приложений.
   * Перехват кнопки HOME происходит **только** на экране блокировки при исчерпании лимита времени.
4. **Блокировка нежелательных приложений**: при попытке ребенка открыть браузер, Play Store или системные настройки приложение сворачивается или перекрывается экраном ввода мастер-пароля.

### 3.3. Настройка по QR-коду со смартфона (Локальный Web UI)
1. **Встроенный HTTP-сервер**: на телевизоре поднимается компактный веб-сервер на локальном порту (например, `8080`).
2. **Экран сопряжения**: на ТВ отображается QR-код вида `http://<IP_телевизора>:8080?token=<секретный_токен>`.
3. **Функции мобильной веб-панели**:
   * Список всех установленных приложений ТВ с переключателями (Разрешено / Заблокировано).
   * Установка дневного лимита времени (например: 30, 45, 60, 90 минут).
   * Настройка расписания сна (например: запрет просмотра после 21:00).
   * Смена мастер-кода стрелок пульта.

### 3.4. Удаленный контроль через Telegram Bot
1. **Механизм связи**: фоновый воркер держит соединение с Telegram Bot API по схеме **Long Polling** (не требует белого IP, VPN или проброса портов).
2. **Авторизация**: бот отвечает только владельцу по `TELEGRAM_ADMIN_CHAT_ID`.
3. **Команды бота**:
   * `/status` — состояние ТВ: статус экрана (вкл/выкл), текущее запущенное приложение, сколько минут осталось сегодня.
   * `/grant <мин>` — добавить ребенку N минут просмотра (например, `/grant 30`).
   * `/lock` — принудительно заблокировать телевизор прямо сейчас.
   * `/unlock` — разблокировать без пароля.
4. **Интерактивные запросы от ребенка**:
   * На экране ТВ при окончании времени отображается кнопка «Попросить ещё время».
   * При нажатии родителю в Telegram приходит уведомление с кнопками:
     * `[+15 мин]` | `[+30 мин]` | `[+1 час]` | `[Отклонить]`
   * При нажатии кнопки таймер на ТВ мгновенно продлевается без перезагрузки.

### 3.5. Защита и запуск сервиса
1. Фоновый сервис мониторинга запускается автоматически при включении телевизора (`BOOT_COMPLETED`) и при выходе из спящего режима (`ACTION_SCREEN_ON`) — **без показа экрана блокировки**.
2. Экран блокировки/ввода пин-кода всплывает **исключительно** при попытке открыть защищенное приложение или при исчерпании лимита времени у ребенка.
3. Поддержка регистрации администратора устройства (`DeviceAdminReceiver`), исключающая удаление приложения ребенком.

## 4. Стек технологий

* **Платформа**: Android TV 7.0+ (API 24+), целевая оптимизация под Android 9 (Sony Bravia ATV3).
* **Язык**: Kotlin.
* **Сетевой стек**: `OkHttp` для Telegram Bot Long Polling.
* **Локальный Web UI**: легковесный встроенный сервер (`NanoHTTPD` или `Ktor Server Netty/CIO`).
* **UI**: Leanback / Jetpack Compose for TV или чистый нативный XML с плавной поддержкой D-Pad навигации.

## 5. План реализации

| Этап | Задачи | Результат |
| :--- | :--- | :--- |
| **Этап 1: Каркас и D-Pad Lock Screen** | Разработка полноэкранного Activity с перехватом событий стрелок `KEYCODE_DPAD_*`, мастер-пароль, анимация ввода. | Рабочий экран ввода пин-кода стрелками. |
| **Этап 2: Сервис таймера и ограничений** | Фоновый `ScreenTimeService`, учет времени разрешенных приложений, вывод оверлея блокировки при исчерпании лимита. Корректная обработка кнопки HOME. | Автономный учет времени и блокировка ТВ. |
| **Этап 3: QR Web Server для смартфона** | Встроенный HTTP-сервер, генерация QR-кода на ТВ, мобильная HTML-страница настроек приложений и лимитов. | Настройка с телефона по домашнему Wi-Fi. |
| **Этап 4: Интеграция Telegram Bot** | Telegram Polling клиент, команды `/status`, `/grant`, `/lock`, `/unlock`, обработка inline-кнопок запроса времени. | Полноценный удаленный контроль через Telegram. |
| **Этап 5: Сборка APK и деплой** | Компиляция релизного APK, установка по ADB на ТВ `192.168.0.102:5555`, финальное тестирование. | Готовое установленное приложение на ТВ. |
